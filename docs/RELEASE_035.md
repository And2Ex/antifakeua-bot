# Release 035 — підписи до медіа та публікація з медіа

- Виправлено обробку фото з описом: якщо новина міститься в підписі до фото, бот аналізує саме підпис як текстову новину.
- Додано підтримку підписів до відео, анімацій, документів і медіагруп.
- Для медіагруп бот збирає файли з одного альбому й прив'язує їх до заявки на публікацію.
- У черзі публікацій адміністратор бачить медіа перед текстом перевірки.
- Якщо заявка має медіа, з'являються дві кнопки: **«Опублікувати з медіа»** і **«Опублікувати без медіа»**.
- Після публікації, пропуску або відхилення медіа очищається з заявки, щоб не накопичувати зайві дані в базі.
- Файли не завантажуються в локальне сховище: тимчасово зберігаються лише Telegram `file_id`, які очищаються після рішення адміністратора.
