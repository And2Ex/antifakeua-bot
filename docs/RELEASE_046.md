# Release v046 — єдина українська мова результатів

## Що змінено

- Результати перевірки завжди формуються українською мовою незалежно від мови оригінального повідомлення або джерел.
- Оригінальні назви каналів, медіа, організацій та власні імена можуть залишатися без перекладу, коли це важливо для точності.
- Оновлено ревізію аналізу до `verdict_policy_v4`, щоб повторна перевірка не повертала старі результати іншою мовою з кешу.
- Виправлено застарілий перелік прикладів вердиктів у `README.md`: розмиті формулювання більше не описуються як доступні результати.

## База даних

Міграція бази не потрібна: ревізія результату зберігається у наявному JSON-полі перевірки.
