# Release 051 — попереднє отримання тексту за посиланням

- Якщо користувач надсилає лише посилання, бот спочатку локально намагається отримати текст публікації без виклику GPT та вебпошуку.
- Якщо зміст доступний, бот непомітно переходить до звичайної повної перевірки з обов’язковим вебпошуком.
- Якщо зміст отримати не вдалося, бот просить скопіювати текст або переслати допис із Telegram; окремої кнопки примусової перевірки не додається.
- Для успішно зчитаної публікації її URL зберігається як оригінальне джерело результату та майбутньої чернетки публікації.
- Локальне читання URL захищене від звернень до приватних, локальних і службових мережевих адрес.
- Додано явну залежність `aiohttp`, яку використовує локальний читач вебсторінок.
