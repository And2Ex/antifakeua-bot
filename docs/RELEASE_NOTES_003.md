# AntiFakeUA Bot — release 003 integrated analytics

## Що додано в цей реліз

### 1. Локальний інфоаналіз без витрат токенів

Після кожної перевірки бот додає блок `Локальний інфоаналіз`:

- основне твердження з тексту;
- виявлені домени й Telegram-джерела;
- ознаки емоційної маніпуляції;
- ризик, що стару новину подано як нову;
- дати й роки, знайдені в тексті;
- орієнтовну вагу перевірки в кредитах.

Цей блок формується локально й не звертається до GPT.

### 2. Перевірка повторів

Додано таблицю `content_history`. Бот запамʼятовує точний хеш тексту й показує, якщо такий самий текст уже траплявся в базі.

Це основа для виявлення повторного поширення старих новин і масових вкидів.

### 3. Кеш більше не списує ліміт

Якщо результат уже є в кеші, бот повертає його без нового GPT-запиту і без списання ліміту користувача.

Це економить токени на популярних фейках і повторних перевірках.

### 4. Репутація джерел

Додано таблиці:

- `sources`;
- `source_mentions`;
- `content_history`;
- `tracked_events`;
- `watch_sources`;
- `usage_logs`;
- `checks`.

Після нової перевірки бот записує знайдені джерела й оновлює їхню базову статистику:

- правда;
- фейки;
- маніпуляції;
- непідтверджено;
- старий контент як новий.

Для кеш-хітів джерело записується як згадка, але репутаційний рахунок не збільшується, щоб не накручувати статистику повторними запитами.

### 5. Команда `/source`

Команда показує репутацію джерела:

```text
/source pravda.com.ua
/source t.me/channel
```

### 6. Підготовка до майбутнього сайту

Схема БД уже містить базові таблиці для:

- сторінок перевірок;
- репутації джерел;
- моніторингу подій;
- списку джерел для спостереження;
- майбутньої аналітики та платних звітів.

## Важливо

OCR, глибокий моніторинг подій, графи звʼязків і сайт ще не додані. Цей реліз додає легке ядро аналітики, яке вже працює в межах Telegram-бота й не потребує додаткових витрат.
