# Release 055 — підтверджена новина без насторожливого проміжного вердикту

- Прибрано видимий вердикт **«Правда з уточненням»** із нових GPT-результатів та JSON-схеми відповіді.
- Якщо головна теза й ключові факти підтверджені, бот повертає **«✅ Правда»**; справді важлива примітка подається окремим абзацом **«Уточнення»**.
- Технічна група `mixed` тепер призначена лише для вердикту **«Маніпуляція»**; істотне спростування головної тези й надалі переходить у **«Частково неправда»** або **«Неправда»**.
- Оновлено внутрішній prompt формування допису для каналу: правдива новина не отримує тривожного проміжного заголовка, а важливе уточнення враховується лише в тексті за необхідності.
- Оновлено ревізію аналізу до `verdict_policy_v7_no_qualified_truth`, тому старі результати переаналізовуються під час повторної перевірки або підготовки публікації.
- Оновлено `README.md`, `METHODOLOGY.md` і `docs/PROMPT_PUBLIC.md`.
