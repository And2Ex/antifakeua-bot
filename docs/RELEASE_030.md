# Release 0.30 — Повна перевірка з короткої позначки

- У позначці QuickCheck назва **AntiFakeUA** стала посиланням на повний збережений висновок із джерелами.
- Відкриття такої перевірки в боті не запускає повторний аналіз і не показує користувачу службові повідомлення про повторне використання результату.
- Автоматичні короткі перевірки зберігаються окремо від черги публікацій власного каналу AntiFakeUA.
- Оновлено README, методологію та публічний опис prompt відповідно до нового сценарію QuickCheck.
