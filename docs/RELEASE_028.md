# Release 0.28 — QuickCheck і новий формат публікацій

## Зміни

- Додано QuickCheck для каналів і груп із режимами ручного та автоматичного використання.
- Автоматичні позначки публікуються лише для дописів із ознаками перевірюваної новини; реклама й неперевірювані повідомлення ігноруються.
- Формат повної перевірки тепер показує коротку причину поруч із вердиктом, коли це потрібно.
- Формат публікації в каналі AntiFakeUA змінено: заголовок теми, посилання на оригінальний допис через рядок «Опубліковано в», пояснення й «Джерела перевірки».
- Публічне посилання на технічну сторінку перевірки прибрано з видимих публікацій.
- Оновлено prompt, методологію та README.
