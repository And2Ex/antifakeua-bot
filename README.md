# AntiFakeUA

**AntiFakeUA** — Telegram-бот для перевірки новин, заяв, дописів із соцмереж і пересланих повідомлень на фейки, маніпуляції та непідтверджену інформацію.

Користувач надсилає новину або твердження, а бот аналізує зміст, звіряє його з відкритими джерелами й повертає короткий зрозумілий висновок із поясненням.

## Можливості

- перевірка текстових новин, заяв, пересланих повідомлень і підписів до медіа;
- гнучкі точні вердикти: наприклад, правда, потребує контексту, оманливе твердження, фейк або непідтверджено;
- коротка причина вердикту й перелік джерел перевірки;
- окрема підготовка новинних дописів для каналу AntiFakeUA після рішення адміністратора;
- 10 безкоштовних перевірок щомісяця та пакети додаткових перевірок;
- збереження повторних результатів для швидшої відповіді.

## QuickCheck для каналів

Адміністратор новинного каналу або групи може підключити коротку автоматичну перевірку нових дописів. Якщо повідомлення містить перевірювану новину, бот додає стислу точну позначку результату: наприклад, **Правда**, **Потребує контексту**, **Фейк** або **Непідтверджено**. Натискання на позначку **AntiFakeUA** відкриває повний висновок із поясненням та джерелами.

QuickCheck не ставить позначок під рекламними, промоційними або неперевірюваними повідомленнями. Це дозволяє використовувати функцію як інструмент прозорості й довіри, а не як рекламне схвалення.

## Ліміти й підтримка

Бот надає **10 безкоштовних перевірок щомісяця**. Для додаткових перевірок доступні пакети:

- **+100 перевірок — 129 грн**;
- **+1000 перевірок — 699 грн**.

Додаткові перевірки додаються до балансу та не згорають під час щомісячного оновлення безкоштовного ліміту. Наразі пакет підтверджується вручну через Monobank:

1. зробити переказ на суму обраного пакета;
2. повернутися до бота й відкрити пункт **«Підтримати»**;
3. саме в цьому розділі надіслати скріншот оплати;
4. після перевірки суми адміністратор додає відповідний пакет.

Якщо новина надіслана як фото, кілька фото або відео з текстовим описом, бот перевіряє саме опис як текст. Саме зображення або відео як джерело тексту в поточній версії не розпізнається.

Для публікації в каналі бот не використовує пояснення фактчеку як готовий допис. Спочатку в базі зберігається лише результат перевірки. В адмін-черзі показуються сторінки по 10 ще не переглянутих перевірок усіх користувачів: кожен заголовок веде до відповідного фактчеку. Лише після натискання адміністратором **«Публікація»** під відкритою перевіркою окремий редакторський запит формує новинну чернетку з перевірених фактів. У готовому дописі одразу під вердиктом відображається клікабельна назва оригінального джерела, якщо посилання на допис доступне. Після перегляду адміністратор вирішує, опублікувати її з оригінальним медіа чи без нього. Для варіанта з фото або відео бот створює окрему завершену коротку версію тексту, оскільки Telegram обмежує підпис до медіа 1024 символами; текст не обривається посеред думки. Перехід до наступної сторінки черги позначає попередні 10 перевірок як пропущені та очищає їхні медіа.

## Модель і вебпошук

Для повної перевірки бот використовує **`gpt-5.4-mini`** через Responses API та примусово викликає інструмент **`web_search`** у кожному запиті фактчеку (`tool_choice="required"`). Використовується стандартний режим обробки API. Редакторський запит для формування канального допису працює на основі вже збереженого фактчеку й не запускає новий пошук.

## Принципи

AntiFakeUA перевіряє конкретне повідомлення, а не автора чи канал загалом. Бот не примушує кожен результат до трьох жорстких категорій: коли точніше сказати «Потребує контексту» або «Непідтверджено», використовується саме такий вердикт. Бот не має робити категоричних висновків без достатніх підтверджень і показує джерела, на яких ґрунтується результат.
