# Release 033 — ліміти та підтвердження підтримки

- У меню **«Мої ліміти»** додано пояснення, як отримати додаткові перевірки через добровільну підтримку проєкту.
- Уточнено сценарій для користувача: після переказу потрібно відкрити **«Підтримати»** і саме в цьому розділі надіслати скріншот оплати.
- Звичайні зображення без активованого режиму підтримки не обробляються як підтвердження переказу; аналіз зображень новин не додавався.
- Прибрано залишкові гілки розрахунку для OCR/аналізу зображень із поточних службових модулів: ліміти та локальна оцінка стосуються текстових перевірок.
- Оновлено `README.md`, `METHODOLOGY.md`, текст розділу підтримки та вебсторінку підтримки.
