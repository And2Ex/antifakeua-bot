# Release 036 — окрема генерація новинного допису

- Фактчек тепер зберігає тільки результат перевірки, пояснення та джерела; текст канального допису під час перевірки не генерується.
- Додано окремий редакторський prompt для новинного допису, який запускається лише після дії адміністратора.
- Для вердикту **«Правда»** чернетка формується як звичайна новина із суттю події, без початку на кшталт «справді» або «підтверджено».
- Під результатом перевірки адміністратора та в адмін-сповіщенні додано кнопку **«📰 Публікація»**, яка відкриває саме цю заявку.
- Черга публікацій також генерує чернетку лише при відкритті конкретної заявки; після першої генерації чернетка зберігається й повторно не витрачає запит.
- Збережено вибір **«Опублікувати з медіа»** / **«Опублікувати без медіа»** та очищення медіа після рішення.
- До таблиці `requests` додано колонку `publication_json`; вона додається автоматично через `schema.sql` при запуску бота.
