# Release 042 — модель, вебпошук і додаткові перевірки

## Зміни

- Для фактчеку використовується `gpt-5.4-mini`.
- Legacy-інструмент `web_search_preview` замінено на актуальний `web_search` у Responses API.
- Для повної перевірки встановлено `tool_choice="required"`, тому при єдиному інструменті `web_search` кожен фактчек виконує вебпошук; редакторська генерація канального допису не робить окремий пошук.
- Безкоштовний щомісячний ліміт змінено на 10 перевірок.
- Додані внутрішні орієнтири для надання додаткових перевірок після підтримки проєкту.
- У розділах «Мої ліміти» й «Підтримати» пояснюється можливість отримати додаткові перевірки після підтримки проєкту.
- В адмін-повідомленні про скріншот кнопки видачі пакета тепер показують відповідну суму.
- Оновлено внутрішній розрахунок API-витрат: тарифи Standard для `gpt-5.4-mini` та вартість виклику web search.

## Neon / міграція

Після запуску `v042` бот змінює старе стандартне значення ліміту `30` на поточне налаштоване значення `FREE_TEXT_LIMIT` для акаунтів, які досі мали обидва старі стандартні поля `30/30`. Стан міграції зберігається разом із застосованим значенням, тому виправлення `FREE_TEXT_LIMIT` у Render також коректно застосовується при наступному запуску. Ручні нестандартні ліміти не змінюються.

Якщо на Render уже задана змінна середовища `FREE_TEXT_LIMIT=30`, її потрібно змінити на `FREE_TEXT_LIMIT=10` перед запуском нової версії.
