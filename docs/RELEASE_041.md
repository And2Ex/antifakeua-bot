# Release v041 — гнучкі точні вердикти

## Зміни

- Вердикт більше не обмежений лише написами **«Правда»**, **«Маніпуляція»**, **«Фейк»**, **«Недостатньо даних»** та **«Інше»**.
- Додано точніші видимі варіанти, зокрема **«Переважно правда»**, **«Потребує контексту»**, **«Оманливе твердження»**, **«Застарілий контекст»**, **«Неправда»**, **«Підробка»** та **«Непідтверджено»**.
- GPT може використати інший короткий нейтральний вердикт, якщо стандартний варіант не передає суть конкретної перевірки.
- До структурованого результату додано `verdict_family`: технічну групу `true`, `mixed`, `false`, `uncertain` або `other`.
- Емодзі, QuickCheck і внутрішня статистика тепер орієнтуються на технічну групу, а не на один фіксований напис.
- Старі збережені результати без `verdict_family` залишаються сумісними: під час перегляду група визначається з попереднього тексту вердикту, а при повторному надсиланні тієї самої новини старий кеш одноразово оновлюється новим аналізом.
- Редакторський промпт канальної публікації враховує точний тип висновку: для «Потребує контексту» не називає повідомлення фейком, а для «Непідтверджено» не подає заяву як встановлений факт.

## База даних

Нові колонки або ручні міграції не потрібні: `verdict_family` зберігається у наявному JSON результату перевірки.
