# Release 043 — публічні тексти підтримки та оформлення джерела

## Зміни

- У користувацьких повідомленнях і актуальній документації прибрано показ конкретних сум та формулювання про придбання пакетів.
- Розділи «Мої ліміти» і «Підтримати» тепер пояснюють, що користувачі, які підтримали проєкт, можуть отримати додаткові перевірки.
- Збережено вимогу надсилати скріншот підтримки саме після відкриття розділу «Підтримати».
- З README, методології та публічного prompt прибрано опис внутрішнього адміністративного процесу підготовки дописів для каналу.
- У готовому канальному дописі першоджерело під вердиктом відображається у форматі `📰` та жирного клікабельного посилання.

## Внутрішня логіка

Внутрішні орієнтири для ручного надання додаткового ліміту залишені в конфігурації та інтерфейсі адміністратора; користувачам вони не показуються.
