# Release v038

## Публікація з медіа

- Виправлено формування підпису до фото, відео та медіаальбомів: HTML більше не обрізається посеред посилання або жирного тексту при ліміті Telegram у 1024 символи.
- Для підпису з медіа бот безпечно скорочує текст і, за потреби, кількість посилань у блоці джерел, не пошкоджуючи розмітку.
- Альбом підтримує фото й відео разом або лише документи; несумісні змішані типи медіа не надсилаються помилковим запитом до Telegram.

## Формат допису каналу

- Одразу під вердиктом відображається назва оригінального джерела.
- Якщо є посилання на оригінальний допис, назва джерела є клікабельною.
- Прибрано підпис `Опубліковано в:` перед назвою джерела.
