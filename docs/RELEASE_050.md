# Release 050 — перевірка новин за посиланням

- Окремі посилання на Instagram, Threads, Facebook, X, Telegram або вебсторінки більше не відхиляються локальним фільтром як повідомлення без змісту. Для поширених соцмереж розпізнаються також вставлені адреси без `https://`.
- Посилання запускає повну перевірку з обов’язковим вебпошуком.
- Якщо публікація закрита, видалена або недоступна для читання, бот чесно повідомляє, що зміст не вдалося перевірити, без вигадування результату.
- Така спроба використовує одну перевірку навіть у разі недоступності сторінки, оскільки запит до аналізу вже виконується.
- Стартова інструкція й довідка тепер прямо пропонують надіслати текст, посилання або пересланий допис із Telegram.
- Оновлено README, методологію та публічний опис prompt.
- У методології прибрано фіксоване число безкоштовних перевірок, оскільки стандартний ліміт тепер керується через адмін-панель.
