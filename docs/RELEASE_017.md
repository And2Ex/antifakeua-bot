# Release 017 — Clean response UI

## Зміни

- Прибрано окремий блок `📌 Деталі:` з відповідей фактчеку.
- Додаткові уточнення тепер додаються як звичайний абзац без зайвого підзаголовка.
- Prompt оновлено так, щоб модель рідше створювала зайві блоки.
- Порожні медіа-повідомлення без тексту тепер ігноруються мовчки, щоб не було спаму після альбомів або пересланих постів.

## Формат відповіді

Вердикт → пояснення → джерела → посилання.
