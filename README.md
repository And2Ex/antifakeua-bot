# AntiFakeUA

**AntiFakeUA** — Telegram-бот для перевірки новин, заяв, дописів із соцмереж і пересланих повідомлень на фейки, маніпуляції та непідтверджену інформацію.

Користувач надсилає текст новини, посилання на онлайн-публікацію або переслане повідомлення, а бот аналізує зміст, звіряє його з відкритими джерелами й повертає короткий зрозумілий висновок із поясненням.

## Можливості

- перевірка текстових новин, заяв, посилань на онлайн-публікації, пересланих повідомлень і підписів до медіа;
- чіткі вердикти: наприклад, правда, маніпуляція, частково неправда, фейк або непідтверджено;
- коротка причина вердикту й перелік джерел перевірки;
- відповіді українською мовою незалежно від мови оригінального допису;
- стандартний безкоштовний місячний ліміт із можливістю отримати додаткові перевірки після підтримки проєкту;
- збереження повторних результатів для швидшої відповіді.

## QuickCheck для каналів

Адміністратор новинного каналу або групи може підключити коротку автоматичну перевірку нових дописів. Для каналу також доступна ручна перевірка останнього отриманого ботом допису через команду `/quickcheck` у приватному чаті. Якщо повідомлення містить перевірювану новину, бот додає стислу точну позначку результату: наприклад, **Правда**, **Частково неправда**, **Фейк** або **Непідтверджено**. Натискання на позначку **AntiFakeUA** відкриває повний висновок із поясненням та джерелами.

У ручному режимі бот не перевіряє дописи сам: адміністратор натискає **«Перевірити останній допис»** у керуванні QuickCheck. Ця кнопка запускає аналіз останнього допису навіть тоді, коли автоматичний попередній відбір не розпізнав його як новину або не поставив позначку. Остаточна публічна позначка все одно створюється лише тоді, коли результат перевірки є доречним для показу під дописом.

## Ліміти й підтримка

Бот надає безкоштовні перевірки в межах місячного ліміту, актуальна кількість якого відображається в самому боті. Користувачі, які підтримали проєкт, можуть отримати додаткові перевірки. Додатковий баланс не згорає під час щомісячного оновлення безкоштовного ліміту.

Щоб передати підтвердження підтримки, потрібно відкрити в боті пункт **«Підтримати»** і надіслати скріншот саме в цьому розділі.

Якщо новина надіслана як фото, кілька фото або відео з текстовим описом, бот перевіряє саме опис як текст. Саме зображення або відео як джерело тексту в поточній версії не розпізнається.

Якщо надіслано лише посилання на допис або вебсторінку, воно одразу обробляється як повна перевірка через обов’язковий вебпошук. Бот намагається прочитати саме пов’язану публікацію та зіставити її твердження з відкритими джерелами. Якщо оригінальна сторінка закрита, видалена або недоступна для надійного читання, бот повідомляє про це без вигадування змісту.

## Модель і вебпошук

Для повної перевірки бот використовує **`gpt-5.4-mini`** через Responses API та примусово викликає інструмент **`web_search`** у кожному запиті фактчеку (`tool_choice="required"`). Використовується стандартний режим обробки API.

## Принципи

AntiFakeUA перевіряє конкретне повідомлення, а не автора чи канал загалом. Бот використовує обмежений набір чітких вердиктів: **Правда**, **Маніпуляція**, **Частково неправда**, **Неправда / Фейк** або **Непідтверджено**. Передусім оцінюється головна теза повідомлення: неперевірена другорядна деталь не занижує підтверджену новину, а правдивий фон не маскує спростовану ключову заяву. Важливі уточнення до підтвердженої новини подаються окремим абзацом і не перетворюються на насторожливий проміжний вердикт. Бот не має робити категоричних висновків без достатніх підтверджень і показує джерела, на яких ґрунтується результат.
