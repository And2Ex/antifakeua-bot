# AntiFakeUA

AntiFakeUA — Telegram-бот для перевірки текстових новин, заяв, дописів із соцмереж і пересланих повідомлень на фейки, маніпуляції та дезінформацію.

Бот допомагає швидко зрозуміти, чи є в повідомленні перевірюване фактичне твердження, наскільки воно підтверджується доступними джерелами, чи немає підміни контексту, перебільшення або емоційного тиску.

## Можливості

- перевірка тексту на фейки, маніпуляції та непідтверджену інформацію;
- аналіз новин, заяв, пересланих повідомлень і дописів із соцмереж;
- відповідь у форматі **вердикт → короткий заголовок → пояснення → джерела**;
- виявлення ознак клікбейту, емоційного тиску та підміни контексту;
- публічний код перевірки, щоб результат можна було переслати іншим;
- кешування повторних перевірок;
- черга публікацій у канал та адмін-функції;
- безкоштовні й платні пакети перевірок у Telegram-боті.

## Технічний стек

- Python 3.13;
- aiogram 3.x;
- OpenAI Responses API з web search;
- FastAPI + Telegram webhook + LiqPay callback;
- PostgreSQL на Neon через `DATABASE_URL`;
- Render Web Service для запуску webhook-сервісу.

## База даних

Поточна версія **не використовує SQLite**. Дані зберігаються в PostgreSQL на Neon, тому кеш, публічні посилання, користувачі, ліміти та платежі не залежать від перезапусків Render.

Для локального запуску після налаштування `.env`:

```powershell
pip install -r requirements.txt
python -m scripts.test_database_connection
python main.py
```

Для розгортання через Neon і Render дивись [`DEPLOY_NEON_RENDER.md`](DEPLOY_NEON_RENDER.md).

## Принцип прозорості

AntiFakeUA не має бути «чорною скринькою». Логіка перевірки описана відкрито: бот аналізує конкретне твердження, шукає підтвердження, відрізняє факти від думок і не робить категоричних висновків, якщо даних замало.

Публічний prompt перевірки доступний у файлі [`docs/PROMPT_PUBLIC.md`](docs/PROMPT_PUBLIC.md).
