# AntiFakeBot 24-05 release 010

## Що змінено

- Прибрано `/menu` з видимого меню команд у приватному чаті.
- У приватному чаті для звичайного користувача показується тільки `/start`.
- У приватному чаті для адміна показуються `/start` і `/admin`.
- У групах показується тільки `/check`.
- Обробник `/menu` залишено приховано для сумісності: якщо хтось введе `/menu` вручну, меню все ще відкриється.

## Чому так

`/start` і `/menu` дублювали одне одного. Для користувача простіше мати одну головну команду — `/start`.
