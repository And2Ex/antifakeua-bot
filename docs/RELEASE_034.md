# Release 034 — уточнення старту й підтримки

- У стартовому повідомленні явно зазначено, що для перевірки можна надіслати текст або переслати повідомлення з Telegram.
- У розділі **«Підтримати»** спрощено текст інструкції без зайвих технічних пояснень.
- Уточнено, що скріншот оплати потрібно надсилати саме в розділі **«Підтримати»**.
