# Release 048 — керування стандартним безкоштовним лімітом

- Стандартний щомісячний free-ліміт перенесено зі змінної середовища до таблиці `app_settings` у PostgreSQL/Neon.
- В адмін-панелі додано розділ **«⚙️ Free-ліміт»**: стандарт можна змінювати кнопками або командою `/setdefaultlimit ЧИСЛО`.
- Нові користувачі отримують поточний стандартний ліміт одразу після реєстрації.
- Для наявних користувачів новий стандарт застосовується лише під час наступного щомісячного поновлення; їхній поточний доступний ліміт не урізається посеред періоду.
- Додатковий баланс за підтримку не залежить від зміни стандартного free-ліміту й не згорає.
- Команда `/setlimit USER_ID ЧИСЛО` тепер створює персональний виняток; команда `/usedefaultlimit USER_ID` повертає користувача до загального стандарту з наступного поновлення.
- Значення `FREE_TEXT_LIMIT` більше не потрібне у `.env` або Render Environment; для нової бази початковий стандарт встановлюється в коді як 10 і далі керується через адмін-панель.
