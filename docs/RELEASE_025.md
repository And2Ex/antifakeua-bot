# Release 025 — Neon PostgreSQL та новий формат відповіді

## Змінено

- Основна база повністю переведена з SQLite на PostgreSQL через `DATABASE_URL`.
- Проєкт підготовлено до бази Neon і деплою вебсервісу на Render.
- Публічні перевірки, кеш, користувачі, ліміти, оплати та статистика більше не залежать від локального `.db`-файлу Render.
- Додано `render.yaml`, `.python-version`, скрипт перевірки підключення до PostgreSQL і інструкцію `DEPLOY_NEON_RENDER.md`.
- Прибрано `__pycache__` та скомпільовані Python-файли з архіву.

## Новий формат фактчеку

Після вердикту бот тепер виводить короткий жирний заголовок, який пояснює суть результату без читання всього пояснення:

```text
✅ Правда

У місті справді запустили новий громадський маршрут

Після підриву 6 червня 2023 року...
```

У prompt окремо заборонено починати пояснення словами «Перевіряється твердження…».
