# Release v044 — вердикт за головною тезою

## Що змінено

- Оновлено правила фактчеку: бот спочатку визначає головну тезу допису й ставить вердикт за тим, чи підтверджується саме вона.
- Додано видимий вердикт **«Частково неправда»** для випадків, де реальний фон або окремі деталі є правдивими, але ключове твердження повідомлення спростовується.
- **«Потребує контексту»** тепер має використовуватися лише тоді, коли головна теза підтверджена, але без важливої обставини створює оманливе враження; цей вердикт не повинен підміняти спростування.
- Для чернеток каналу заборонено абстрактні заголовки на кшталт «Потребує контексту» чи «Є часткове підтвердження»: заголовок має містити встановлений факт або чітке спростування.
- Додано ревізію аналізу `main_claim_v2`: старий кеш при повторній перевірці того самого тексту одноразово оновлюється за новими правилами.

## Приклад

Якщо допис стверджує, що бензину в Криму «немає навіть за талонами», а джерела свідчать про продаж за талонами або обмеження продажу, очікуваний висновок — **«Частково неправда»** або **«Неправда»**, а не **«Потребує контексту»**.

## База даних

Ручна міграція не потрібна: маркер ревізії зберігається в уже наявному JSON результату перевірки.
