# Release v039

## Завершений текст дописів із медіа

- Пояснено й враховано обмеження Telegram: підпис до фото, відео або альбому містить максимум 1024 символи після обробки HTML-розмітки.
- Канальна чернетка тепер містить окреме поле `media_body`: короткий, але завершений новинний абзац для публікації з медіа.
- Бот більше не обрізає текст медіапублікації посеред речення й не завершує її випадковим `...`.
- Для старих незавершених чернеток із медіа, у яких ще немає `media_body`, під час наступного відкриття публікації бот заново сформує чернетку в новому форматі.

## Коректне врахування довжини Telegram

- Довжина HTML-повідомлення тепер перевіряється за видимим текстом після видалення тегів і декодування HTML-сутностей, а не за технічним рядком із прихованими URL у посиланнях.
- Завдяки цьому клікабельне джерело під вердиктом не змушує бот без потреби скорочувати нормальний текст допису.

## Формат канального допису

- Формат збережено: одразу під вердиктом показується назва оригінального джерела як посилання на оригінальний допис, без слів `Джерело` або `Опубліковано в`.
