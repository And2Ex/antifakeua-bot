# AntiFakeUA Bot release 006 — меню і передтестова чистка

## Що змінилось

- У меню команд Telegram залишено тільки базові команди:
  - `/start` — запуск і головне меню;
  - `/menu` — відкрити меню;
  - `/check` — перевірити текст або reply.
- Адміну додатково показується тільки `/admin`.
- Інші команди не видалені, але приховані з меню Telegram. Їх можна вводити вручну.
- Додано нормальне стартове повідомлення з кнопками:
  - як користуватись;
  - про бота;
  - чому можна довіряти;
  - мої ліміти;
  - купити перевірки;
  - репутація джерела;
  - відгук;
  - адмін-панель для ADMIN_IDS.
- Адмін-панель переведена на inline-кнопки замість великого списку команд.
- Локальний інфоаналіз більше не додається у відповідь користувачу.
- Історія контенту, джерела й репутаційна база залишені як технічний фундамент для майбутньої аналітики.
- Повідомлення про баланс більше не додається після кожної перевірки. Воно зʼявляється лише коли ліміт майже закінчився або вже вичерпаний.
- У requirements залишено `uvicorn[standard]`, щоб `run_webhook.py` запускався без ручного встановлення uvicorn.

## Що перевірити після встановлення

1. Запустити `python main.py`.
2. Відкрити `/start` — має зʼявитися головне меню з кнопками.
3. Перевірити меню команд Telegram — не має бути довгого списку.
4. Надіслати тестову новину — відповідь має бути без блоку локального інфоаналізу.
5. Натиснути “Мої ліміти”.
6. Натиснути “Купити перевірки”.
7. Якщо користувач є в `ADMIN_IDS`, відкрити “Адмін-панель”.
8. Запустити `python run_webhook.py` і перевірити `http://127.0.0.1:8000/`.
