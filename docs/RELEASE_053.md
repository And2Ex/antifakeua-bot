# Release 053 — підтримка сторінок-агрегаторів UKR.NET

- Виправлено отримання новин із посилань формату `ukr.net/news/details/...`: читач тепер бачить заголовок і анонс у шаблоні сторінки UKR.NET навіть тоді, коли текст не лежить у стандартних OpenGraph/JSON-LD/`<p>` блоках.
- Для картки UKR.NET бот шукає посилання **«Читати докладніше»** та, якщо воно веде на публічне першоджерело, намагається отримати повний текст новини вже з нього.
- Якщо першоджерело не відкривається, але на сторінці UKR.NET є змістовний заголовок або анонс, перевірка може запускатися на доступному тексті картки.
- Логіка списання ліміту не змінена: перевірка використовується лише після успішного отримання змісту публікації; невдале читання URL ліміт не витрачає.
