# Release 026 — примітка про запуск після простою

## Змінено

- У стартове повідомлення бота додано коротку примітку: після тривалого простою перша дія може виконуватися з невеликою затримкою, поки сервіс запускається.
- Примітка пояснює можливу затримку через використання безкоштовної інфраструктури з автоматичним засинанням під час бездіяльності.
