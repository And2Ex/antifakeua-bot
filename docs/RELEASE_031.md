# Release 0.31

- Виправлено помилкове повідомлення про відсутність прав адміністратора в QuickCheck.
- Перевірка налаштувань каналу спочатку підтверджує права самого бота на публікацію, а потім права адміністратора.
- Для груп додано зрозуміле повідомлення, якщо бота ще не призначено адміністратором.
- Додано діагностичний лог для помилок `getChatMember`, щоб помилки Telegram API не маскувалися під відсутність прав.
