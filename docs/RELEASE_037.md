# Release v037

## Нова черга публікацій

- Адмін-черга тепер показує один список із максимум 10 непереглянутих перевірок усіх користувачів.
- Кожен рядок містить вердикт і короткий заголовок-посилання на повний фактчек.
- Відкриття перевірки з черги не запускає створення канального допису й не витрачає окремий редакторський запит.
- Під відкритим фактчеком для адміністратора відображається кнопка **«📰 Публікація»**.
- Натискання цієї кнопки генерує готовий допис для каналу через окремий промпт і показує кнопки публікації з медіа або без нього.
- Кнопка **«Наступні 10»** позначає поточну сторінку як пропущену і очищає медіа цих записів.
- Для нових фактчеків у JSON-результат додано коротке поле `queue_title`; для старих записів список використовує безпечний скорочений текст із уже збереженої перевірки.

## Сумісність

- Нових колонок бази даних не потрібно.
- Уже створена колонка `publication_json` продовжує зберігати чернетку тільки після дії адміністратора.
