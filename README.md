# AntiFakeUA

**AntiFakeUA** — Telegram-бот для перевірки новин, тверджень, дописів із соцмереж і пересланих повідомлень на фейки, маніпуляції та непідтверджену інформацію.

Користувач надсилає новину або твердження — бот аналізує зміст, перевіряє доступні джерела та повертає короткий і зрозумілий висновок.

## Можливості

* перевірка текстових новин і тверджень;
* аналіз пересланих повідомлень і публікацій;
* визначення, чи містить повідомлення перевірюваний факт;
* короткий структурований результат із поясненням;
* публічне посилання на результат перевірки;
* кешування повторних перевірок;
* система лімітів і пакетів перевірок.

## Формат відповіді

Відповідь бота формується у вигляді:

**вердикт → короткий заголовок → пояснення → джерела**

Це дозволяє швидко зрозуміти результат перевірки навіть без читання повного пояснення.

## Принцип роботи

AntiFakeUA створений як відкритий інструмент фактчекінгу.

Бот аналізує зміст повідомлення, шукає підтвердження у відкритих джерелах, відокремлює фактичні твердження від думок та оцінок і формує висновок лише на основі доступних даних.

Якщо підтвердження недостатньо — бот прямо повідомляє про це без категоричних висновків.
