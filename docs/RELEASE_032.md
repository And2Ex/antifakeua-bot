# Release 032 — підтримка Monobank і теми QuickCheck

- Додано відправлення автоматичної позначки QuickCheck у ту саму тему групи, де опубліковано перевірюваний допис.
- Поточний інтерфейс оплати замінено на добровільну підтримку через Monobank із ручним наданням додаткового ліміту.
- Додано режим очікування скріншота підтримки після відкриття розділу `/support`.
- Додано сповіщення адміністратору зі скріншотом та кнопками швидкого надання додаткових перевірок.
- Звичайні зображення без активного режиму підтримки більше не трактуються як підтвердження переказу.
- Застарілий LiqPay callback вимкнено в активному вебінтерфейсі.
