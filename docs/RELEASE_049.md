# Release 049 — примусовий ручний QuickCheck останнього допису

- Кнопка **«🔎 Перевірити останній допис»** тепер запускає повну коротку перевірку незалежно від попереднього локального фільтра новинності.
- Якщо автоматичний QuickCheck увімкнено, але локальний відбір не визначив останній допис як новину, адміністратор усе одно може перевірити його вручну.
- Автоматичний режим і далі використовує локальний фільтр, щоб не витрачати перевірки на очевидно непридатні повідомлення.
- Остаточне рішення, чи публікувати коротку позначку під дописом, після ручного запуску визначається результатом повної перевірки.
- Оновлено пояснення QuickCheck у користувацьких текстах, README, методології та публічному описі prompt.
