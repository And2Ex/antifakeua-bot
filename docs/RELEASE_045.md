# Release v045 — чіткі вердикти без «Потребує контексту»

## Що змінено

- Прибрано видимий вердикт **«Потребує контексту»**, який надто часто використовувався як невизначений проміжний висновок.
- Вердикти обмежено чітким набором: **Правда**, **Правда з уточненням**, **Маніпуляція**, **Частково неправда**, **Неправда**, **Фейк**, **Підробка**, **Непідтверджено**, а також неперевірювані типи.
- Додано правило: непідтверджена другорядна деталь не знижує вердикт із **«Правда»**, якщо головна теза та ключові факти підтверджені.
- **«Маніпуляція»** використовується тільки для суттєво оманливої подачі підтверджених фактів, а не як заміна обережності.
- **«Частково неправда»** використовується, коли фон реальний, але ключова теза допису суперечить джерелам.
- Оновлено промпт формування канального допису, щоб заголовок залишався новинним і при уточненні або спростуванні.
- Додано ревізію аналізу `verdict_policy_v3`: повторна перевірка старого тексту не повертатиме висновок зі старою схемою вердиктів із кешу.
- Якщо адміністратор відкриває публікацію для старої перевірки, вона автоматично переаналізується перед формуванням канального допису, щоб у канал не потрапляв застарілий розмитий вердикт.

## База даних

Міграція бази не потрібна: ревізія й технічна група вердикту зберігаються у наявному JSON-результаті перевірки.
