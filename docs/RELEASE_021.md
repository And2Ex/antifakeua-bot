# Release 021 — admin notifications

Додано адмін-сповіщення в приватний чат адміністратора.

## Нове

- Кнопка `🔔 Сповіщення` в адмін-панелі.
- Можна вмикати або вимикати сповіщення прямо з бота.
- Сповіщення приходять про:
  - нового користувача;
  - додавання бота в групу;
  - нову перевірку;
  - активацію пакета перевірок.
- Налаштування зберігається в базі даних у таблиці `app_settings`.

## База даних

Додано таблицю:

```sql
app_settings(key, value, updated_at)
```

Таблиця створюється автоматично через `init_db()`.
