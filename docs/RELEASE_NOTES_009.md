# Release 009 — import and feedback routing fix

## Виправлено

- Виправлено падіння запуску через `ImportError: cannot import name HOW_TO_TEXT`.
- `/help` тепер використовує актуальний обʼєднаний текст `ABOUT_TEXT`.
- Виправлено обробник feedback: він більше не перехоплює всі звичайні текстові повідомлення. Тепер відгук приймається тільки якщо користувач натиснув кнопку “Написати відгук” або ввів `/feedback`.

## Що перевірити

1. `python main.py` запускається без ImportError.
2. У приватному чаті звичайний текст новини йде на перевірку, а не губиться в feedback-обробнику.
3. Кнопка “Відгук” → “Написати відгук” зберігає наступне повідомлення як feedback.
