# Release 029

- Повідомлення очікування замінено на анімацію `Перевіряю`, `Перевіряю.`, `Перевіряю..`, `Перевіряю...`.
- Для повної перевірки повідомлення очікування надсилається без звуку, проходить щонайменше один цикл, видаляється перед фінальною відповіддю.
- Для автоматичного QuickCheck після первинного локального відбору одразу публікується тихе повідомлення очікування, яке після аналізу редагується в короткий вердикт.
- Автоматична позначка більше не надсилається як reply: вона займає місце одразу після допису, який перевіряється.
- Якщо після глибшої перевірки допис виявився рекламним або непридатним для публічної позначки, повідомлення очікування видаляється без вердикту.
