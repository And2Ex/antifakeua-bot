# AntiFakeUA

**AntiFakeUA** — Telegram-бот для перевірки новин, заяв, дописів із соцмереж і пересланих повідомлень на фейки, маніпуляції та непідтверджену інформацію.

Користувач надсилає новину або твердження, а бот аналізує зміст, звіряє його з відкритими джерелами й повертає короткий зрозумілий висновок із поясненням.

## Можливості

- перевірка текстових новин, заяв і пересланих повідомлень;
- розрізнення правди, фейку, маніпуляції та випадків, коли даних недостатньо;
- коротка причина вердикту й перелік джерел перевірки;
- підготовка перевірених дописів для публікації в каналі AntiFakeUA;
- безкоштовний ліміт і можливість отримати додаткові перевірки після добровільної підтримки проєкту;
- збереження повторних результатів для швидшої відповіді.

## QuickCheck для каналів

Адміністратор новинного каналу або групи може підключити коротку автоматичну перевірку нових дописів. Якщо повідомлення містить перевірювану новину, бот додає стислу позначку результату: **Правда**, **Маніпуляція** або **Фейк**. Натискання на позначку **AntiFakeUA** відкриває повний висновок із поясненням та джерелами.

QuickCheck не ставить позначок під рекламними, промоційними або неперевірюваними повідомленнями. Це дозволяє використовувати функцію як інструмент прозорості й довіри, а не як рекламне схвалення.

## Принципи

AntiFakeUA перевіряє конкретне повідомлення, а не автора чи канал загалом. Бот не має робити категоричних висновків без достатніх підтверджень і показує джерела, на яких ґрунтується результат.
