# Release 052 — надійніше отримання тексту за посиланням

- Виправлено читач публічних URL: мережеве з'єднання використовує IPv4, щоб уникнути збоїв у середовищах без працездатного вихідного IPv6.
- Запит сторінки використовує сумісний браузерний User-Agent, оскільки частина публічних сайтів блокує спеціалізовані bot User-Agent ще до повернення тексту публікації.
- Розширено витягнення змісту: підтримано OpenGraph/Twitter metadata, JSON-LD (`headline`, `description`, `articleBody`) і текст публічних Telegram-дописів.
- Додано серверні журнальні повідомлення `LINK READER: ...`, щоб за логами Render було видно причину невдалого отримання посилання: DNS, HTTP-статус, тип відповіді або відсутність тексту.
- Поведінка для користувача не змінюється: якщо текст за URL отримано, бот мовчки виконує фактчек; якщо ні — просить надіслати текст або переслати Telegram-допис без списання перевірки.
