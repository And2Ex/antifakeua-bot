# Release 047 — ручний QuickCheck останнього допису

- У приватному керуванні `/quickcheck` для каналу додано кнопку **«🔎 Перевірити останній допис»**.
- Ручна перевірка запускає коротку публічну позначку лише для останнього допису каналу, який бот уже отримав; списку попередніх дописів не створюється.
- У вимкненому автоматичному режимі бот запам’ятовує тільки останній допис каналу, але не витрачає ліміт і не запускає аналіз самостійно.
- Ручний запуск використовує доступний баланс адміністратора, який натиснув кнопку.
- Для збереження останнього допису додано службові поля у `channel_settings`; вони створюються автоматично під час `init_db()`.
- Для медіагруп зберігається текстовий підпис альбому, навіть якщо останній елемент альбому не містить окремого підпису.
- Оновлено README, методологію, публічний опис QuickCheck, стартову довідку та опис Telegram-команди.
