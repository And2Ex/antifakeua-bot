# Release 054 — прямий фактчек посилань через вебпошук

- Прибрано локальний HTML-парсер посилань і спеціальні обробники сайтів-агрегаторів: підтримувати окреме витягнення тексту для кожного сайту ненадійно та складно.
- Окреме посилання тепер одразу передається у повну перевірку через `gpt-5.4-mini` з обов’язковим інструментом `web_search`.
- Для посилання зберігається URL як оригінальне джерело перевірки, щоб воно відображалося у результаті та могло використовуватися в майбутній публікації.
- Якщо сторінка закрита, видалена або її зміст неможливо прочитати через вебпошук, бот не вигадує зміст і повертає обережний висновок; оскільки повний аналіз уже запускався, перевірка списується.
- Прибрано залежність `aiohttp` і файл `services/link_reader.py`, які більше не потрібні.
- Оновлено користувацькі пояснення, методологію та публічний prompt.
