# Release v040

## Виправлення відображення фактчеку

- Прибрано уламки доменних посилань на кшталт `(who.int`, які модель інколи залишала в тексті пояснення.
- Відкриття вже збереженої перевірки з черги тепер повторно форматує структурований результат, тому старі записи також відображаються без таких уламків, якщо у них є `result_json`.
- Посилання `📌 Оригінальний допис` залишається окремою клікабельною кнопкою-рядком під перевіркою.
- Для майбутніх перевірок prompt забороняє додавати домени й посилання в `summary` або `blocks`: джерела мають бути тільки у списку джерел.
- Довгі назви джерел тепер скорочуються як назви матеріалів, а не автоматично замінюються доменом.
